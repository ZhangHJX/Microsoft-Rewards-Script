# State transfer command interface

- updated_at: 2026-09-17
- author: Codex
- status: implemented; local-tests-passed

DONE: state:export and state:import accept paths as arguments and key/account through environment variables. Export uses a private staging file, syncs ciphertext and publishes without replacing existing output. Import reads from a no-follow file descriptor with a size bound and calls the authenticated restore path. Errors print a fixed status, with no account, key or local path. The recommended transfer directory is ignored by git.

DONE: build and 214 tests pass; targeted ESLint, Prettier and diff checks pass. Nine new tests invoke real subprocesses and cover round-trip, output privacy, missing/invalid/argument keys, unknown command, existing file protection, corrupted/symlink/oversized input and account-lock contention.

Reassessment: command integration is ready for a cloud transport adapter, but no secret has been provisioned and no remote state has been uploaded. Do not treat successful local restoration as cloud deployment acceptance. Remote freshness/retention and cross-runner concurrency remain next priorities. The todo index was reconciled with current evidence to remove stale implementation tasks.
