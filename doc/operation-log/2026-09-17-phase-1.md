## Delivered

Added an independent synthetic-fixture CLI under `scripts/validation/`, configuration at `config/validation.example.json`, and CN/HK fixtures under `tests/fixtures/validation/`. Missing or invalid balances remain unknown; zero and negative observed deltas are preserved. Observations do not establish task credit or live market compatibility.

The config is specific to this CLI. Network, login and reward-action capabilities must all be false; setting true rejects the input rather than enabling an implementation. It is not a global safety switch for upstream `npm start`. No production executors were changed.

## Findings and reassessment

Two characterization tests reproduce defects in the actual compiled upstream FlyoutDashboard mapper: two absent balance sources become zero, and a null primary balance overrides a valid fallback with zero. These tests document existing behavior, not desired behavior. The production defects remain unfixed.

Keep the upstream structure and focused fork patches. The next priority is the real balance-parser contract: expand offline cases, inspect callers, define unknown handling, then update the contract and regression expectations together. Do not infer production correctness from the independent CLI.

Not tested: real login, authentication challenges, Rewards actions, account eligibility, CN/HK live compatibility, Linux/GitHub Actions execution, session persistence or notifications. Task acknowledgement and partial business-data contracts also remain future work. No credential, live action, workflow or deployment was introduced in this phase.
